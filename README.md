# Sentiment Analysis on Reviews using NLP

This project focuses on building a sentiment analysis system that classifies customer reviews as **positive** or **negative** using Natural Language Processing (NLP) and Machine Learning techniques. It is designed to understand user opinions from text data and provide accurate sentiment predictions.

## 🔹 Project Overview

The application takes user reviews as input, processes the text using NLP techniques, and predicts whether the sentiment expressed is positive or negative. This type of system is widely used in product analysis, customer feedback systems, and social media monitoring.

## 🔹 Features

- Text preprocessing using NLTK  
- TF-IDF vectorization for feature extraction  
- Logistic Regression classifier for prediction  
- Real-time sentiment prediction through user input  
- Simple and easy-to-use interface

## 🔹 Technologies Used

- Python  
- NLTK  
- Scikit-learn  
- Flask  

## 🔹 Dataset

Amazon Fine Food Reviews Dataset (sourced from Kaggle).  
*Note: The dataset is not included in this repository due to size limitations.*
